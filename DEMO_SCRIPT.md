# GPS Project Demo Script

1. Open the app in the Android emulator.
2. Allow location permission.
3. Open the emulator's three-dot menu, select Location, enter coordinates, and click Set Location.
4. Press Get Current Location and show the latitude/longitude values.
5. Press Start GPS Updates and show the app receiving updates.
6. Press Set Boundary Center Here to set the current location as the geofence center.
7. Change the emulator location and show the inside/outside boundary status changing.
8. Press Stop GPS Updates.
