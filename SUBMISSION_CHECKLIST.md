# GPS Project Submission Checklist

- [ ] App builds in Android Studio.
- [ ] App runs on emulator or device.
- [ ] Location permission prompt works.
- [ ] App displays latitude and longitude.
- [ ] App shows live location updates.
- [ ] App shows the geofence/boundary status.
- [ ] Demo PDF or video includes screenshots/explanation.
- [ ] Code is pushed to GitHub.
- [ ] GitHub repo link is submitted in Blackboard.
- [ ] Skill PDF is submitted only if using this project for a skill.
